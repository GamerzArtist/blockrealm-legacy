## 2026-03-05 - Procedural Terrain Memoization Cache
**Learning:** Procedural voxel games call terrain, noise, and biome lookups repeatedly for the same coordinate coordinates (especially during generation, tree/decoration placement, and coordinate checking). Re-calculating noise maps repeatedly causes major CPU overhead. Implementing a simple, seed-aware `Map`-based cache dramatically speeds up coordinates checks. When the cache is larger, standard FIFO evictions can be slower in V8 than simply calling `.clear()` on the entire cache because `.clear()` is highly optimized, avoids iterating keys, and avoids multiple lookup/deletes.
**Action:** Always use seed-aware, size-bounded Map caching for deterministic mathematical/noise-based terrain generation functions, and clear the Map completely when full instead of performing manual FIFO item evictions.
