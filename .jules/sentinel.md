## 2026-03-01 - Android WebView Open Navigation and Missing Content Security Policy
**Vulnerability:** The application was vulnerable to WebView frame navigation hijacking and arbitrary page loading because `MainActivity.java` did not override `shouldOverrideUrlLoading` inside its custom `WebViewClientCompat`. Additionally, the game HTML templates lacked a Content Security Policy (CSP), allowing potential script or stylesheet injection.
**Learning:** WebView-based hybrid applications require strict navigation safeguards. In hybrid frameworks, omitting explicit domain/URL-scheme routing validations in `shouldOverrideUrlLoading` leaves the WebView client susceptible to navigating outside local application domains upon encountering dynamic redirects or external link interactions.
**Prevention:** Always implement dual-layered security: 1) Override both standard and WebResourceRequest signatures of `shouldOverrideUrlLoading` in WebView clients to enforce strict whitelisting of the application scheme/domain (e.g., `https://appassets.androidplatform.net/`). 2) Implement a strict Content Security Policy meta-tag in all package index files to prevent unauthorized dynamic resources from executing in the local origin context.
