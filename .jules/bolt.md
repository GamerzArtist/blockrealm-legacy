## 2025-05-20 - Procedural Terrain Calculation Caching
**Learning:** Procedural noise generation (`fbm` / value noise) for chunk heightmap and biome determination is heavily evaluated repeatedly during chunk meshing, decoration, surface calculation, and entity spawning. Redundant noise calls (such as calculating temperature/moisture multiple times in nested biome helpers) severely degrade world streaming performance. Using a bounded `terrainCache` Map (cleared via `.clear()` when full) provides a ~36% speedup in chunk terrain evaluation without JS engine iterator overhead.
**Action:** When caching hot-path procedural data, use a bounded Map that clears completely via `.clear()` when reaching max size rather than iterator-based FIFO deletion, and ensure caches are cleared when changing seed/world context.
