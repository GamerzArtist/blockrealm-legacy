# Palette's Journal - Critical Learnings Only

## 2026-08-07 - Theme-Aligned High-Contrast Keyboard Focus
**Learning:** In pixel-art and voxel games, the default browser focus ring looks completely out of place and breaks immersion. Standard modern web design focus indicators (such as smooth rings or subtle drop shadows) also contrast poorly with dark backgrounds and retro interfaces. A double outline with a pixel-style yellow/gold color (`#ffeb3b`) matches the game's retro aesthetic perfectly while satisfying the WCAG contrast requirements.
**Action:** Use high-contrast pixelated yellow outlines with `outline: 4px double #ffeb3b !important` and shadow backdrops for keyboard navigation focus styling in retro gaming platforms.
