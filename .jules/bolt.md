## 2026-08-12 - Terrain Generation Caching
**Learning:** Procedural terrain noise in JavaScript (`fbm`/`valueNoise`) is a major performance bottleneck for voxel game terrain generation. Since terrain coordinates are queried sequentially and frequently overlap across adjacent chunk boundaries and chunk decoration passes, repeated procedural noise calculation wastes massive CPU cycles. Implementing a simple, bounded `terrainCache` Map that clears completely via `.clear()` when bounds (e.g., 10,000 entries) are reached avoids both the massive CPU procedural math overhead and the garbage-collection/JS engine overhead associated with manual FIFO iterator deletions.
**Action:** When working with procedural calculations in JavaScript hot paths, implement bounded cache Maps and clean them completely with `.clear()` when full to maximize performance and avoid degrading the JS engine with iterator generation.
