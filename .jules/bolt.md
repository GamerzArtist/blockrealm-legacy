## 2026-08-28 - Bounded terrainCache Map Optimization
**Learning:** Procedural terrain noise calculation (`terrainInfo`) is called heavily during chunk generation, decoration, surface sampling, and mob spawning. Caching `terrainInfo` results in a bounded `terrainCache` Map indexed by bit-packed integer coordinate keys `((x & 0xffff) << 16) | (z & 0xffff)` significantly eliminates redundant multi-octave FBM noise calculations. Clearing the cache via `.clear()` when reaching bounds (10,000 entries) or switching world seeds avoids JS engine FIFO deletion iterator overhead and prevents cross-seed cache leakage.
**Action:** Always clear bounded Map caches completely using `.clear()` when bounds or scope context change to maintain high JS engine execution efficiency without memory leaks.
