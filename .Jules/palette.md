## 2026-08-02 - Keyboard Focus States in Canvas-based Voxel Web UIs
**Learning:** Game UIs running alongside a canvas element often disable focus indicators using `outline: none`, which renders keyboard navigation completely invisible to screen readers and keyboard-only players. Since touch-control elements in mobile-first PWAs are styled as HTML overlays, adding custom, theme-aligned `focus-visible` styles with custom pixel colors (like `#70d05b`) and `outline-offset` keeps keyboard focus states visually intuitive and consistent with the game's retro voxel aesthetic, without breaking visual immersion.
**Action:** Always replace general `outline: none` on interactive canvas overlay elements with tailored `:focus-visible` outlines matching the game's key action/accent colors to preserve both accessibility and aesthetic continuity.
