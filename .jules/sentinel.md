## 2026-08-10 - Hardening WebView Navigation and Content Security Policy
**Vulnerability:** The Android launcher WebView lacked frame navigation overrides (`shouldOverrideUrlLoading`), allowing potential unauthorized navigation to arbitrary remote websites inside the app wrapper. Additionally, the web interface lacked a Content Security Policy (CSP), making it vulnerable to Cross-Site Scripting (XSS) and unauthorized external resource loading.
**Learning:** Legacy web-to-native wrappers often focus on local asset interception without locking down client-side page-navigation boundaries or enforcing origin restrictions. This allows open-ended redirects or embedded frames to breach origin limits.
**Prevention:** Always restrict frame navigation in `WebViewClient.shouldOverrideUrlLoading` to local asset URLs ('https://appassets.androidplatform.net/' and 'about:blank'), and enforce a strict Content Security Policy meta tag on all shipped pages, keeping the offline boundary hermetically sealed.
