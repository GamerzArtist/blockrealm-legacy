## 2026-08-08 - Immersive High-Contrast Focus & ARIA Indicators
**Learning:** For immersive browser games (like voxel sandboxes), typical system focus rings disrupt visual gameplay immersion, leading developers to unfortunately set `outline: none`. However, this breaks keyboard accessibility completely. Creating a custom, high-contrast gold double-outline styled with deep drop-shadows via CSS `:focus-visible` maintains the game's retro aesthetic while offering 100% compliant contrast and clarity for keyboard navigators. Furthermore, icon-only buttons with custom/emoji glyphs (such as ▦, ✦, Ⅱ, ⛏) must always be paired with explicit `aria-label` attributes so screen readers can describe the buttons' actions correctly.
**Action:** Always implement a dedicated, game-theme-aligned `:focus-visible` outline in `style.css` rather than disabling outlines, and ensure all non-text-based interactive buttons include matching descriptive `aria-label` or `title` properties.
